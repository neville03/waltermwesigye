Sign in once on this device with a GitHub access key. Your changes are saved straight to the website.

How do I get an access key?
  1. Open GitHub's new access key page and sign in.
  2. Name it Website editor and pick an expiry date, for example one year.
  3. Under Repository access, choose Only select repositories and pick waltermwesigye.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above.

The key stays on this device only. On a shared computer, use Sign out when you're done.
